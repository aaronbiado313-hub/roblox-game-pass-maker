# Roblox Game Pass Maker - Contributing Guide

Thank you for your interest in contributing! This document provides guidelines and instructions for contributing.

## Code of Conduct

- Be respectful and inclusive
- Report issues responsibly
- Provide constructive feedback
- Respect intellectual property

## How to Contribute

### 1. **Report Bugs**
- Check existing issues first
- Provide detailed description
- Include browser/OS information
- Add screenshots if applicable

### 2. **Suggest Features**
- Open a GitHub Discussion
- Describe the feature clearly
- Explain the use case
- Include mockups if helpful

### 3. **Submit Code**
- Fork the repository
- Create feature branch: `git checkout -b feature/amazing-feature`
- Commit changes: `git commit -m 'Add amazing feature'`
- Push to branch: `git push origin feature/amazing-feature`
- Open Pull Request

## Development Setup

1. Clone repository: `git clone https://github.com/aaronbiado313-hub/roblox-game-pass-maker.git`
2. Open `index.html` in browser
3. Make changes
4. Test thoroughly
5. Commit and push

## Coding Standards

- Use meaningful variable names
- Add comments for complex logic
- Follow existing code style
- Test across browsers
- Ensure mobile compatibility

## Testing Checklist

- [ ] Works on Chrome/Firefox/Safari/Edge
- [ ] Responsive on mobile
- [ ] Form validation working
- [ ] No console errors
- [ ] Keyboard shortcuts work
- [ ] Local storage persists
- [ ] File upload functions
- [ ] All links work

## Pull Request Process

1. Update README if needed
2. Add/update tests
3. Ensure code passes linting
4. Provide clear PR description
5. Link related issues
6. Request reviews

## Questions?

- Create an issue with [QUESTION] tag
- Start a discussion
- Check documentation first
